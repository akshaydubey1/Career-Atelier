# Career Atelier

**By Akshay Dubey** · [github.com/akshaydubey1](https://github.com/akshaydubey1)

Open-source skills for job seekers. Drop them into any AI tool that supports the open [Agent Skills](https://agentskills.io) format: Claude, Claude Code, ChatGPT and Codex, Cursor, GitHub Copilot and VS Code, Gemini CLI, and [many more](https://agentskills.io/home).

## Skills

| Skill | What it does |
| --- | --- |
| [Resume Tailor](skills/akshay-dubey-resume-tailor/) | Scores a job against your résumés. It skips jobs below a 75% match, reuses a résumé that already fits, or tailors one to 85% or more without inventing experience. You get résumé and cover letter PDFs, plus a private job list. |

## Install a skill

1. Download this repo (**Code → Download ZIP**) or clone it.
2. Copy the skill's folder from `skills/` into your tool's skills:
   - **Claude app:** zip the skill folder and upload it as a custom skill ([how skills work](https://support.claude.com/en/articles/12512176-what-are-skills)).
   - **Claude Code:** copy the folder to `~/.claude/skills/`.
   - **Other tools:** follow your tool's skills page, linked from the [Agent Skills client list](https://agentskills.io/home).
3. Paste a job description to start.

Each skill's own README has the details.

## Principles

- **Honest.** No skill here invents experience, titles, metrics or credentials.
- **Efficient.** Each skill does the least work needed and reuses what already exists.
- **Yours.** Everything a skill produces carries only your name.
